複合関係詞 Whomever

文法と構文の説明

Whomever は「～する人は誰でも」「～する人を誰でも」という意味を持つ複合関係詞で、文頭または文中で使われます。

  • 文頭にWhomever： Whomever you choose, you will be fine. （あなたが選んだ誰でも問題ありません。）
  • 文中にWhomever： You can choose whomever you like. （あなたが好きな人を誰でも選んで構いません。）

問題

以下の単語を並べ替えて正しい文を作成しましょう。（和訳を参考にしてください）

問題 1： (you / Whomever / choose / be / will / fine / you / ,) - あなたが選んだ誰でも問題ありません。

解答： Whomever you choose, you will be fine.

解説： 文頭に Whomever を置き、選択を指しています。

  • Whomever： ～する人は誰でも（複合関係詞）
  • you： あなた（代名詞）
  • choose： 選ぶ（動詞）
  • you： あなた（代名詞）
  • will： ～だろう（助動詞）
  • be： ～である（動詞）
  • fine： 良い（形容詞）

問題 2： (like / You / whomever / can / invite / you) - あなたが好きな人を誰でも招待できます。

解答： You can invite whomever you like.

解説： 文中に Whomever を置いて、許可を表しています。

  • You： あなた（代名詞）
  • can： ～できる（助動詞）
  • invite： 招待する（動詞）
  • whomever： ～する人を誰でも（複合関係詞）
  • you： あなた（代名詞）
  • like： 好む（動詞）

問題 3： (help / Whomever / you / need / should / you / ,) - あなたが必要としている人を誰でも助けるべきです。

解答： Whomever you need, you should help.

解説： 文頭に Whomever を置いて、対象を指しています。

問題 4： (job / Whomever / you / hire / the / can / have / you / ,) - あなたが雇った人はその仕事を任せられます。

解説： 文頭に Whomever を置いて選択を示しています。

問題 5： (am / I / know / I / Whomever / is / best / for / decide) - 私は誰がその仕事に最適であるかを知っています。

解答： I know whomever I am best for the job.
