現在完了形（経験：肯定文・疑問文・否定文）

文法説明

現在完了形の経験は「have + 過去分詞」で「～したことがある」を表します。疑問文では Have を文頭に置き、否定文では have not（haven’t）を使います。

例: I have been to Kyoto. / Have you been to Kyoto? / I have not been to Kyoto.

用語解説

  • 現在完了形: have + 過去分詞で経験などを表す形。
  • 過去分詞: 動詞の変化形。been は be、seen は see、had は have の過去分詞。
  • have not / haven’t: 現在完了形の否定。
  • Have + 主語 + 過去分詞 ... ?: 経験を尋ねる疑問文の語順。

問題

以下の単語を並べ替えて正しい文章を作りましょう。（和訳も参考にしてください）

問題1: (been / Kyoto / I / have / to) - 私は京都に行ったことがあります。

解答: I have been to Kyoto.

解説: have been to + 場所 で「～へ行ったことがある」という経験を表します。

  • I: 私は（代名詞）
  • have: 現在完了形を作る助動詞
  • been: be の過去分詞
  • to: ～へ（前置詞）
  • Kyoto: 京都（固有名詞）

問題2: (to / you / Kyoto / Have / been / ?) - あなたは京都に行ったことがありますか。

解答: Have you been to Kyoto?

解説: Have を文頭に置いて経験を尋ねます。

  • Have: 現在完了形の疑問文を作る助動詞
  • you: あなたは（代名詞）
  • been: be の過去分詞
  • to: ～へ（前置詞）
  • Kyoto: 京都（固有名詞）

問題3: (been / have / Kyoto / I / not / to) - 私は京都に行ったことがありません。

解答: I have not been to Kyoto.

解説: have not + 過去分詞で経験がないことを表します。

  • I: 私は（代名詞）
  • have: 現在完了形を作る助動詞
  • not: ～ない（否定語）
  • been: be の過去分詞
  • to: ～へ（前置詞）
  • Kyoto: 京都（固有名詞）

問題4: (shooting / have / I / star / seen / a) - 私は流れ星を見たことがあります。

解答: I have seen a shooting star.

解説: see の過去分詞 seen を使います。

  • I: 私は（代名詞）
  • have: 現在完了形を作る助動詞
  • seen: see の過去分詞：見た
  • a: 1つの（冠詞）
  • shooting: 流れる（形容詞的用法）
  • star: 星（名詞）

問題5: (a / star / Have / seen / you / shooting / ?) - あなたは流れ星を見たことがありますか。

解答: Have you seen a shooting star?

解説: Have + 主語 + seen の語順で経験を尋ねます。

  • Have: 現在完了形の疑問文を作る助動詞
  • you: あなたは（代名詞）
  • seen: see の過去分詞：見た
  • a: 1つの（冠詞）

問題6: (shooting / have / seen / I / star / not / a) - 私は流れ星を見たことがありません。

解答: I have not seen a shooting star.

解説: have not seen で「見たことがない」と表します。

  • I: 私は（代名詞）

問題7: (sushi / I / had / have) - 私は寿司を食べたことがあります。

解答: I have had sushi.

解説: have の過去分詞 had を使い、食べた経験を表します。

  • I: 私は（代名詞）
  • have: 現在完了形を作る助動詞
  • had: have の過去分詞：食べた
  • sushi: 寿司（名詞）

問題8: (had / Have / sushi / you / ?) - あなたは寿司を食べたことがありますか。

解答: Have you had sushi?

解説: Have を文頭に置き、過去分詞 had を続けます。

  • Have: 現在完了形の疑問文を作る助動詞
  • you: あなたは（代名詞）
  • had: have の過去分詞：食べた
  • sushi: 寿司（名詞）

問題9: (sushi / had / haven't / I) - 私は寿司を食べたことがありません。

解答: I haven't had sushi.

解説: haven't は have not の短縮形です。

  • I: 私は（代名詞）
  • haven't: have not の短縮形
  • had: have の過去分詞：食べた
  • sushi: 寿司（名詞）
