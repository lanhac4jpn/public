be動詞・一般動詞の過去形

文法説明

be動詞の過去形は was / were を使います。疑問文では be動詞を文頭に、否定文では was not / were not を使います。一般動詞の過去形は went、did などを使い、疑問文は Did + 主語 + 動詞の原形、否定文は 主語 + didn’t + 動詞の原形です。

例: You were busy yesterday. / Were you busy yesterday? / You weren’t busy yesterday.

用語解説

  • were: are の過去形で、you などに使います。
  • weren’t: were not の短縮形です。
  • 過去形: 過去の動作を表す動詞の形です。
  • 原形: go、do などの基本の形です。
  • Did: 過去の疑問文を作る助動詞です。
  • didn’t: did not の短縮形です。

問題

以下の単語を並べ替えて正しい文章を作りましょう。（和訳も参考にしてください）

問題1: (yesterday / busy / were / You) - あなたは昨日忙しかったです。

解答: You were busy yesterday.

解説: were は be動詞 are の過去形です。

  • You: あなたは（代名詞）
  • were: ～でした（be動詞の過去形）
  • busy: 忙しい（形容詞）
  • yesterday: 昨日（副詞）

問題2: (busy / yesterday / you / Were / ?) - あなたは昨日忙しかったですか。

解答: Were you busy yesterday?

解説: be動詞 Were を文頭に置いて疑問文を作ります。

  • Were: ～でしたか（be動詞の過去形）
  • you: あなたは（代名詞）
  • busy: 忙しい（形容詞）
  • yesterday: 昨日（副詞）

問題3: (busy / weren't / yesterday / You) - あなたは昨日忙しくありませんでした。

解答: You weren't busy yesterday.

解説: weren't は were not の短縮形です。

  • You: あなたは（代名詞）
  • weren't: ～ではありませんでした（be動詞の過去形の否定）
  • busy: 忙しい（形容詞）
  • yesterday: 昨日（副詞）

問題4: (went / the sea / I / to) - 私は海に行きました。

解答: I went to the sea.

解説: went は go の過去形です。

  • I: 私は（代名詞）
  • went: 行った（go の過去形）
  • to: ～へ（前置詞）
  • the sea: 海（名詞句）

問題5: (the sea / you / Did / to / go / ?) - あなたは海に行きましたか。

解答: Did you go to the sea?

解説: Did を文頭に置き、動詞は原形 go にします。

  • Did: 過去の疑問文を作る（助動詞）
  • you: あなたは（代名詞）
  • go: 行く（動詞の原形）
  • to the sea: 海へ（前置詞句）

問題6: (go / didn’t / I / to / the sea) - 私は海に行きませんでした。

解答: I didn’t go to the sea.

解説: didn’t の後は原形 go を使います。

  • I: 私は（代名詞）
  • didn’t: ～しなかった（否定表現）
  • go: 行く（動詞の原形）
  • to the sea: 海へ（前置詞句）

問題7: (this morning / homework / I / did / my) - 私は今朝宿題をしました。

解答: I did my homework this morning.

解説: did は do の過去形です。

  • I: 私は（代名詞）
  • did: した（do の過去形）
  • my: 私の（所有格）
  • homework: 宿題（名詞）
  • this morning: 今朝（時を表す語句）

問題8: (homework / Did / this morning / you / do / your / ?) - あなたは今朝宿題をしましたか。

解答: Did you do your homework this morning?

解説: Did の後は動詞の原形 do です。

  • Did: 過去の疑問文を作る（助動詞）
  • you: あなたは（代名詞）
  • do: する（動詞の原形）
  • your: あなたの（所有格）
  • homework: 宿題（名詞）
  • this morning: 今朝（時を表す語句）

問題9: (my / this morning / didn’t / homework / I / do) - 私は今朝宿題をしませんでした。

解答: I didn’t do my homework this morning.

解説: didn’t の後は do を使います。

  • I: 私は（代名詞）
  • didn’t: ～しなかった（否定表現）
  • do: する（動詞の原形）
  • my homework: 私の宿題（名詞句）
  • this morning: 今朝（時を表す語句）
